# PaperPolish v0.1.0

PaperPolish 首个公开版本：面向学术写作的交互式论文打磨桌面工作台。

- 支持词汇、句子与段落润色，以及基于要点生成段落。
- 并排查看原文与结果，通过可编辑、可勾选的修改要点进行多轮打磨。
- 提供术语库、参考文库检索和 Ultra 生成器—评估器迭代。
- 支持会话与文件夹管理、历史记录、Markdown / JSON 导出及中英文界面。
- 支持按模块配置模型、输出语言和提示词，以及可选的本地 Copilot provider。

## 下载与使用

下载 `PaperPolish-1.0.0-portable.exe`，在 Windows x64 上直接运行。在设置中配置自己的模型服务地址、API key 和模型，再创建会话开始使用。使用本地 Copilot provider 时，请先完成 copilot-api 的本地认证。

本次发布版本与应用内部版本均为 **v0.1.0**；便携版下载文件名为 `PaperPolish-1.0.0-portable.exe`。

源码提供 ZIP 和 TAR.GZ 下载；`SHA256SUMS.txt` 包含发布附件的 SHA-256 校验值。GitHub 页面还提供对应标签的 Source code 下载。
